# 이미지 전송 에러

### 1. 개요

1. 유저에게 받은 이미지를  restClient를 이용해서 Fast API서버에 전달 시도
2. 전송은 성공했지만, Fast API 서버쪽에 빈 body가 전달됨.
3. 422 Unprocessable Content: [no body] 에러 발생

```markdown
2026-01-21 16:43:05 [http-nio-8080-exec-5] ERROR c.b.o.s.RealAiClientService - 이미지 분석 통신 오류 (URI: /analyze-image-ingredients): 422 Unprocessable Content: [no body]
2026-01-21 16:43:05 [http-nio-8080-exec-5] ERROR o.a.c.c.C.[.[.[.[dispatcherServlet] - 서버 통신 오류: 422 Unprocessable Content: [no body]] with root cause
```

### 2. 문제의 코드

```java
@Slf4j
@Service
@Profile("prod")
public class RealAiClientService implements AiClientService {

    private final RestClient restClient;

    private record PythonResponseWrapper<T>(List<T> result) {}

    public RealAiClientService(@Value("${ai-server.url}") String aiServerUrl) {
        HttpClient httpClient = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(5))
                .build();
        JdkClientHttpRequestFactory factory = new JdkClientHttpRequestFactory(httpClient);
        factory.setReadTimeout(Duration.ofSeconds(60));

        this.restClient = RestClient.builder()
                .baseUrl(aiServerUrl)
                .requestFactory(factory)
                .build();
    }

    private List<IngredientAnalysisResponse> sendMultipartRequest(String uri, MultipartFile file, String preference, String userId) {
        log.info("[prod] 이미지 분석 요청 URI: {}, User: {}", uri, userId);

        MultipartBodyBuilder builder = new MultipartBodyBuilder();
        builder.part("file", file.getResource());
        builder.part("preference", preference);
        builder.part("userId", userId);

        try {
            PythonResponseWrapper<IngredientAnalysisResponse> response = restClient.post()
                    .uri(uri) // 전달받은 URI 사용
                    .contentType(MediaType.MULTIPART_FORM_DATA)
                    .body(builder.build())
                    .retrieve()
                    .body(new ParameterizedTypeReference<PythonResponseWrapper<IngredientAnalysisResponse>>() {});

            return response != null ? response.result() : Collections.emptyList();
        } catch (Exception e) {
            log.error("이미지 분석 통신 오류 (URI: {}): {}", uri, e.getMessage());
            throw new RuntimeException("AI 서버 통신 오류: " + e.getMessage());
        }
    }
}
```

### 3. 문제의 원인

1. “JdkClientHttpRequestFactory - 비교적 높은(?) 버전의 http 통신 객체 사용”

- RestClient를 사용했기 때문에 JdkClientHttpRequestFactory를 표준으로 사용했다.
- JdkClientHttpRequestFactory는 멀티파트 전송 시 **Streaming** 방식을 사용한다.
- 스트리밍 방식은 전체 데이터 크기를 미리 계산하지 않고 데이터를 조각내어 보내는 Transfer-Encoding: chunked를 사용하는데, Transfer-Encoding: chunked 헤더를 붙여 데이터를 조각내어 보낸다.

### **“이 방식 때문에, HTTP 헤더에 Content-Length가 포함되지 않는다”**

1. “엄격한 Fast API의 통신 규약”
- FastAPI는 내부적으로 python-multipart라는 라이브러리를 사용하여 멀티파트 데이터를 파싱한다.
- 많은 ASGI 서버(Uvicorn 등)와 멀티파트 파서는 보안(DoS 공격 방지)과 메모리 효율을 위해, 요청이 들어올 때 Content-Length 헤더를 참조하여 버퍼 크기를 미리 할당하려고 시도한다.
- Content-Length가 없고 Transfer-Encoding: chunked로 들어오면, 파이썬 서버의 하위 계층에서 바디(Body) 데이터를 정상적으로 조립하지 못하거나, 데이터가 아직 도착하지 않은 것으로 간주하여 빈 값으로 상위 애플리케이션(FastAPI)에 넘겨버린다.
- FastAPI는 함수 파라미터에 정의된 files를 찾으려 하지만, 바디가 비어 있으므로 "필수 값이 누락되었다"고 판단하여 422 에러를 반환한다.

### 4. 문제 해결

1. SimpleClientHttpRequestFactory & restTemplate 사용
- Fast API서버의 처리 방식을 바꾸는건 불가능 했기 때문에 Spring쪽에서 요청 방식 변경
- Fast API서버와 같은 데이터를 메모리에 버퍼링해서 Content-Length를 명시적으로 보내는 SimpleClientHttpRequestFactory로 변경
- SimpleClientHttpRequestFactory객체를 표준으로 사용하는 restTemplate로 변경
- 문제 해결 후 코드

```java
@Slf4j
@Service
@Profile("prod") // 운영(prod) 환경에서만 작동
public class RealAiClientService implements AiClientService {

    private final RestTemplate restTemplate;
    private final String aiServerUrl;

    private record PythonResponseWrapper<genericType>(List<genericType> result) {}

    public RealAiClientService(@Value("${ai-server.url}") String aiServerUrl) {
        this.aiServerUrl = aiServerUrl;

        SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();

        factory.setConnectTimeout(5000);
        factory.setReadTimeout(120000);

        this.restTemplate = new RestTemplate(factory);
        log.info("[prod] RealAiClientService가 초기화되었습니다. Target URL: {}", aiServerUrl);
    }

    private List<IngredientAnalysisResponse> sendImageRequest(String uri, List<MultipartFile> files, String userId) {
        log.info("[prod] 이미지 분석 요청: URI={}, Count={}, User={}", uri, files.size(), userId);

        MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
        if (files != null) {
            for (MultipartFile file : files) {
                body.add("files", file.getResource());
            }
        }
        body.add("userId", userId);
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.MULTIPART_FORM_DATA);
        HttpEntity<MultiValueMap<String, Object>> requestEntity = new HttpEntity<>(body, headers);

        try {
            ResponseEntity<PythonResponseWrapper<IngredientAnalysisResponse>> responseEntity =
                    restTemplate.exchange(
                            aiServerUrl + uri,
                            HttpMethod.POST,
                            requestEntity,
                            new ParameterizedTypeReference<PythonResponseWrapper<IngredientAnalysisResponse>>() {}
                    );
            PythonResponseWrapper<IngredientAnalysisResponse> response = responseEntity.getBody();
            return response != null ? response.result() : Collections.emptyList();

    }
```
